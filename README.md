# Simple Calculator

A modern, responsive calculator web application built with HTML, CSS, and JavaScript.

## Features

- ✨ Clean and modern UI
- 🎨 Beautiful gradient background
- ⌨️ Keyboard support
- 📱 Fully responsive design
- 🔢 Basic arithmetic operations (+, -, *, /)
- ✅ Decimal number support
- 🗑️ Delete and clear functions
- ⚠️ Division by zero protection

## How to Use

1. Open `index.html` in your web browser
2. Click number buttons or use your keyboard to input numbers
3. Click operator buttons (+, -, *, /) to perform calculations
4. Press the = button or Enter key to see the result
5. Use C button or Escape key to clear
6. Use DEL button or Backspace key to delete the last digit

## Keyboard Shortcuts

- **Numbers**: 0-9
- **Operators**: +, -, *, /
- **Decimal**: .
- **Calculate**: Enter or =
- **Clear**: Escape
- **Delete**: Backspace

## File Structure

- `index.html` - HTML structure of the calculator
- `styles.css` - Styling and responsive design
- `script.js` - Calculator logic and functionality
- `README.md` - Documentation

## Live Demo

You can view the calculator by opening `index.html` in your browser.
